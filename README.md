## Features

* ⚡ Fast and stable VPN connection
* 🔐 State-of-the-art traffic encryption
* 🌍 Servers in various countries
* 🛡️ Kill Switch
* 🔀 Split tunneling
* 🔌 Support for WireGuard / IKEv2
* 🤖 Automatic selection of the optimal server
* 🌑 Modern Dark UI
* 📱 Responsive interface
* 🔒 No-Logs policy
* ⭐ Favorite servers
* 📊 Traffic statistics
